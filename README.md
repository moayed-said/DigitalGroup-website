# DigitalGroup Website

[Demo](https://moayed-said.github.io/DigitalGroup-website/)

## Setup

Make sure to install the dependancies:

````bash
# yarn
yarn install

# npm
npm install

# pnpm
pnpm install
````

## Development Server
````bash
# npm
npm run dev
````
